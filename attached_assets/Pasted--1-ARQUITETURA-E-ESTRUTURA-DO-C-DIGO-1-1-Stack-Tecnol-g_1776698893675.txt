3. SISTEMA DE ANIMAÇÕES (Motion Framework)
3.1 Background Animated Blobs
// Blob Roxo (Top-Left)
Propriedades físicas:
  - Dimensões: 288px × 288px (w-72 h-72)
  - Posição inicial: top: 80px, left: -80px
  - Blur radius: 96px (blur-3xl)

Animação:
  - Eixo X: 0px → 100px → 0px (movimento horizontal)
  - Eixo Y: 0px → 50px → 0px (movimento vertical)
  - Duração: 20 segundos
  - Easing: easeInOut (aceleração suave)
  - Loop: Infinito
  
// Blob Teal (Bottom-Right)
Propriedades físicas:
  - Dimensões: 384px × 384px (w-96 h-96)
  - Posição inicial: bottom: 80px, right: -80px
  - Blur radius: 96px (blur-3xl)

Animação:
  - Eixo X: 0px → -100px → 0px (movimento inverso)
  - Eixo Y: 0px → -50px → 0px (movimento inverso)
  - Duração: 15 segundos
  - Easing: easeInOut
  - Loop: Infinito
Técnica Utilizada: Lissajous Curve Pattern (movimento orgânico em forma de 8)

3.2 Header Entry Animation
Initial State (t=0):
  - translateY: -100px (fora da viewport)
  - opacity: 0 (invisível)

Final State (t=0.6s):
  - translateY: 0px (posição normal)
  - opacity: 1 (totalmente visível)

Transition:
  - Duration: 600ms
  - Easing: easeOut (desaceleração no final)
  - Delay: 0ms
Efeito Resultante: Slide-in from top com fade-in simultâneo

3.3 Cards Staggered Entry Animation
Para cada card (index = 0 a 5):

Initial State:
  - translateY: 50px (abaixo da posição final)
  - opacity: 0

Final State:
  - translateY: 0px
  - opacity: 1

Transition:
  - Duration: 500ms
  - Delay: index × 100ms (0ms, 100ms, 200ms, 300ms, 400ms, 500ms)
  - Easing: easeOut
Efeito Resultante: Cascata de aparecimento (choreographed animation)

3.4 Card Hover Interactions
// Scale + Rotation Animation
whileHover:
  - scale: 1.05 (aumento de 5%)
  - rotate: [0deg, -2deg, 2deg, 0deg] (wiggle effect)
  - transition: 300ms

// Icon Rotation
whileHover:
  - rotate: 360deg (rotação completa)
  - transition: 600ms
  
// Text Scale
  - transform: scale(1.1)
  - transition: 300ms

// Shine Effect (Sweep Animation)
initial: translateX(-100%)
whileHover: translateX(100%)
duration: 600ms
3.5 Tap/Click Feedback
whileTap:
  - scale: 0.95 (compressão de 5%)
  - transition: instantânea (~100ms)
Princípio de UX: Haptic Feedback Visual (simula pressão física)

3.6 Footer Fade-in
Initial State:
  - opacity: 0

Final State:
  - opacity: 1

Transition:
  - Duration: padrão (~300ms)
  - Delay: 800ms (aguarda outras animações)

15. ANIMATION TIMING FUNCTIONS
15.1 Bezier Curves Utilizadas
easeOut (desaceleração):
  cubic-bezier(0, 0, 0.2, 1)
  - Início rápido
  - Final suave
  - Uso: Entrada de elementos

easeInOut (simétrico):
  cubic-bezier(0.4, 0, 0.6, 1)
  - Aceleração no início
  - Desaceleração no final
  - Uso: Movimentos contínuos (background blobs)

linear:
  cubic-bezier(0, 0, 1, 1)
  - Velocidade constante
  - Uso: Rotações (360deg)
15.2 Duration Guidelines
< 100ms  : Micro-interactions (tap feedback)
300ms    : Hover states, transições rápidas
500-600ms: Animações de conteúdo, rotações
800ms+   : Fade-ins finais, transições de página
15-20s   : Animações ambiente (background)
